# find47-dashboard

[FIND/47](https://find47.jp/)プロジェクトの美しい写真を可視化するWebベースのダッシュボードです。インタラクティブな地図や没入感のあるスライドショービューアーを通じて、日本全国47都道府県の写真を楽しむことができます。

## デモ

- **[ダッシュボード](https://code4fukui.github.io/find47-dashboard/)**: 写真の分布を示すインタラクティブな日本地図。
- **[キーワード検索](https://github.com/code4fukui/find47-dashboard)**: 検索キーワードに基づいてスライドショーを起動するツール。

## 機能

- **インタラクティブなコロプレスマップ**: 都道府県ごとの写真数を色分けした地図で可視化します。各地域には写真の枚数と全国順位が表示されます。
- **都道府県別写真ギャラリー**: 地図上で都道府県をクリックすると、その下に写真のサムネイルギャラリーが即座に読み込まれます。
- **没入感のあるスライドショー**: 任意の都道府県やキーワード検索結果に対して、フルスクリーンでゆったりとアニメーションするスライドショーを起動します。写真の詳細（タイトル、撮影者）がオーバーレイ表示されます。
- **キーワード検索**: 「桜」「城」「海」などのキーワードで全都道府県の写真を検索し、専用のスライドショーで結果を表示します。

## 使い方

1. **地図を見る**: [ダッシュボード](https://code4fukui.github.io/find47-dashboard/)を開きます。日本地図上で都道府県ごとの写真の分布を確認できます。
2. **都道府県を選択する**: 都道府県をクリックすると統計情報が表示され、ページ下部にその都道府県の写真ギャラリーが読み込まれます。
3. **スライドショーを起動する**: ギャラリー上部のリンク（例: 「北海道 スライドショー表示へ」）をクリックすると、その都道府県のフルスクリーンアニメーションスライドショーが開きます。
4. **キーワードで検索する**: [キーワード検索](https://github.com/code4fukui/find47-dashboard)ページにアクセスして検索ワードを入力し、「open」をクリックすると、全コレクションの中から一致する写真のスライドショーが表示されます。

## データと技術

- **写真データ**: [FIND/47プロジェクト](https://find47.jp/)のデータを使用し、CSVデータは[code4fukui/find47](https://github.com/code4fukui/find47)によって作成されています。
- **スライドショービューアー**: [yurayura-photo-viewer](https://github.com/code4fukui/yurayura-photo-viewer)を使用しています。
- **アプリ開発**: [Code for FUKUI](https://code4fukui.github.io/)によって開発されました。
